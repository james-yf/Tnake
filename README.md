# Tnake 

## What will it be?
A snake game using **React** for the frontend and a **Rust** backend (via **Tauri**) (_hence the T in the repo name_).

## Why am I making it?
It's OFC a very simple and unoriginal game idea — however, irrespective of the end product, I thought making something using these frameworks and Rust would be beneficial for the following reasons:
* **I want to introduce myself to Rust...**
* **I want to further develop my React knowledge, which I've gained recently from my CS frontend subject.**
